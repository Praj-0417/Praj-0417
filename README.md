### ♻️ ScrapSaathi — AI-Powered Waste Management Platform

A waste-management platform built around pickup workflows, service-oriented architecture, and AI-powered discovery.

- Architected **5 microservices** behind an API gateway, with JWT authentication, OTP verification, and RBAC across **4 user roles**.
- Implemented Redis rate limiting with HTTP 429 responses beyond the configured **1,000 requests per 15 minutes**.
- Implemented cache-aside with a **1-hour TTL**, measuring p95 latency reduction from **31 ms to 3 ms** with a reported **95%+ cache hit rate**.

**Tech:** React · Node.js · Express.js · MongoDB · Redis · FastAPI · FAISS · RAG

### 🧠 Multi-Modal Brain Tumor Segmentation

A three-stage medical-imaging pipeline combining YOLOv8m, LoRA-fine-tuned MedSAM, and nnU-Net.

- Reported Dice scores of **0.76 on SSA** and **0.64 on pediatric** unseen datasets.
- Reported improvements of **33% and 42%** over the selected baseline, respectively.
- Used T1ce, T2, and FLAIR inputs with ROI masking and LoRA fine-tuning.

**Tech:** PyTorch · YOLOv8 · MedSAM · LoRA · nnU-Net · OpenCV
